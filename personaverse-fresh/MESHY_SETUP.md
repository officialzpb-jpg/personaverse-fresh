# Meshy AI Integration Setup

## Step 1: Get API Key (FREE)

1. Go to https://www.meshy.ai/
2. Click "Get Started" or "Sign Up"
3. Create account with email or Google
4. Verify email
5. Go to Dashboard → API Keys
6. Copy your API key

## Step 2: Add Environment Variable

Add to Vercel or `.env.local`:

```bash
MESHY_API_KEY=your_meshy_api_key_here
```

## Step 3: Pricing (FREE TIER)

- **200 credits/month** - FREE
- 1 text-to-3D = ~10 credits
- 1 image-to-3D = ~15 credits
- That's ~20 avatars per month FREE!

## Step 4: Usage

The system is ready! Use the `MeshyCreator` component to create avatars.

✅ Text-to-3D (describe your avatar)
